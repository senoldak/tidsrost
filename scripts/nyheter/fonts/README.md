# Yazı tipleri

Kapak ve sosyal medya görsellerini çizen `bilde.mjs` ve `fjord.mjs` bu dosyaları kullanır. Hepsi SIL Open Font
License 1.1 ile lisanslıdır; lisans metinleri bu klasördedir. Görsellerin kendisine lisans bir kısıt koymaz.

| Dosya | Kaynak | Lisans |
| --- | --- | --- |
| `Archivo.ttf` | Archivo (değişken), The Archivo Project Authors, https://github.com/Omnibus-Type/Archivo | `OFL-Archivo.txt` |
| `SourceSerif4.ttf` | Source Serif 4 (değişken), Adobe | `OFL-SourceSerif4.txt` |
| `TidsrostTittel.ttf` | `Archivo.ttf`'den türetildi: wght 900, wdth 78 | `OFL-Archivo.txt` |
| `TidsrostTung.ttf` | `Archivo.ttf`'den türetildi: wght 800, wdth 100 | `OFL-Archivo.txt` |
| `TidsrostSemi.ttf` | `Archivo.ttf`'den türetildi: wght 600, wdth 100 | `OFL-Archivo.txt` |
| `TidsrostBrod.ttf` | `Archivo.ttf`'den türetildi: wght 450, wdth 100 | `OFL-Archivo.txt` |

Türetilmiş kesimler fontTools `varLib.instancer` ile sabitlendi ve kendi aileleriyle yeniden adlandırıldı (OFL madde 3
ve 4: değiştirilmiş sürüm aynı lisansla dağıtılır, telif bildirimi korunur; Archivo'nun korunan yazı tipi adı yoktur).
Telif ve lisans satırları yazı tipi dosyalarının ad tablosunda durur.
